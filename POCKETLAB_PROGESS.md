## 6. Machine Learning Feature

The planned ML feature is **spending pattern clustering using K-Means**.

The model groups weeks or months with similar spending behavior. For example, it might discover:
- Low-spending periods
- Periods with frequent small purchases
- Periods with unusually high spending

These are possible interpretations, not guaranteed results.

### `pocketlab/ml/features.py`

A function named `build_spending_profiles(df, period="W")` is planned to:

1. Validate that `date`, `category`, and `amount` exist.
2. Convert dates and amounts into appropriate data types.
3. Remove invalid dates, invalid amounts, and non-positive expenses.
4. Group transactions by week or month.
5. Calculate:
   - `total_amount`
   - `transaction_count`
   - `average_amount`
6. Calculate each category's share of spending.
7. Return a DataFrame with one row per spending period.

### `pocketlab/ml/clustering.py`

A function named `cluster_spending(df, n_clusters=3, period="W")` is planned to:

1. Generate spending profiles.
2. Apply `log1p` to selected spending metrics.
3. Scale the features using `StandardScaler`.
4. Train `KMeans` with `random_state=42` and `n_init=10`.
5. Add a `cluster` column to the profiles.
6. Return `(profiles, model, scaler)`.

The current baseline is exploratory. Numeric cluster labels do not automatically mean “good” or “bad” spending. We must inspect cluster summaries before assigning human-readable descriptions.

The model needs enough distinct spending periods for the requested number of clusters. Three clusters require at least three valid periods.

## 7. ML Experiment Workflow

The notebook `03_machine_learning.ipynb` will load the CSV and use the clustering function.

Example:

```python
import pandas as pd
from pathlib import Path

from pocketlab.ml.clustering import cluster_spending

csv_path = Path("../data/raw/expenses.csv")
df = pd.read_csv(csv_path)

profiles, model, scaler = cluster_spending(
    df,
    n_clusters=3,
    period="W"
)

profiles.head()
```

Summarize the discovered clusters:

```python
summary = profiles.groupby("cluster").agg(
    average_weekly_spending=("total_amount", "mean"),
    average_transactions=("transaction_count", "mean"),
    average_transaction_value=("average_amount", "mean"),
    number_of_weeks=("total_amount", "count"),
)

summary.round(2)
```

Visualize the results:

```python
import matplotlib.pyplot as plt

for cluster_id, group in profiles.groupby("cluster"):
    plt.scatter(
        group["total_amount"],
        group["average_amount"],
        label=f"Cluster {cluster_id}"
    )

plt.xlabel("Total weekly spending (VND)")
plt.ylabel("Average transaction value (VND)")
plt.title("PocketLab: Spending Patterns")
plt.legend()
plt.show()
```

The notebook should be used to inspect whether the patterns are meaningful before integrating the model into Flask.
